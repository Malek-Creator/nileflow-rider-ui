## 2. Backend Microservice Architecture

The backend infrastructure is decoupled into domain-driven microservices engineered for extreme resilience, high concurrency, and zero-loss edge synchronization.

### 2.1 Service Catalog & Responsibilities

| Service Name | Primary Language | Storage & Queues | Core Responsibility |
|---|---|---|---|
| **Dispatch & Order Matcher** | Go 1.22 | Redis Cluster, PostgreSQL | Ingests orders, computes corridor batching along Waiyaki Way/Kilimani, and broadcasts 25s acceptance offers. |
| **Telemetry & Geospatial Router** | Rust / C++ | ClickHouse, Kafka | Ingests rider GPS pings every 3s, computes speed telemetry, and monitors geofenced waiting corridors. |
| **Finance & M-Pesa Settlement** | Node.js (NestJS) | PostgreSQL (ACID), Redis | Connects with Safaricom Daraja B2C APIs, handles zero-tariff instant wallet cashouts, tips, and escrow releases. |
| **Proof of Delivery & KYC Vault** | Python (FastAPI) | AWS S3 / MinIO, PostgreSQL | Verifies 4-digit SMS OTPs, digitally signs SHA-256 glass signatures, and conducts OCR validation for NTSA licenses. |
| **Offline Sync & Edge Gateway** | Go 1.22 | SQLite Server, Redis Pub/Sub | Manages two-way sync queues, resolves offline conflicts using CRDTs, and manages emergency SMS fallbacks. |

## 6. Offline Edge Engine & Resilient Synchronization Daemon

In dense commercial corridors or underground parking bays (such as Westgate Mall Dock C or Delta Corner Towers B1), cell networks frequently drop. Nile Flow's SQLite engine enforces **Local Zero-Loss Queuing**:

```typescript
// src/offline/syncEngine.ts
import SQLite from 'react-native-sqlite-storage';

export interface SyncEvent {
  id: string;
  eventType: 'POD_COMPLETED' | 'TELEMETRY_BREADCRUMB' | 'MERCHANT_HANDOVER';
  payload: string; // JSON stringified
  timestamp: string;
  retryCount: number;
}

export class OfflineSyncDaemon {
  private db: SQLite.Database;

  constructor(db: SQLite.Database) {
    this.db = db;
  }

  async enqueueEvent(type: SyncEvent['eventType'], payload: object): Promise<void> {
    const id = `EV-${Date.now()}-${Math.random().toString(36).substr(2, 9)}`;
    const sql = `INSERT INTO edge_sync_queue (id, event_type, payload, timestamp, retry_count) VALUES (?, ?, ?, ?, 0)`;
    await this.db.executeSql(sql, [id, type, JSON.stringify(payload), new Date().toISOString()]);
  }

  async processSyncQueue(): Promise<{ synced: number; remaining: number }> {
    const [results] = await this.db.executeSql('SELECT * FROM edge_sync_queue ORDER BY timestamp ASC LIMIT 50');
    let synced = 0;

    for (let i = 0; i < results.rows.length; i++) {
      const row: SyncEvent = results.rows.item(i);
      try {
        const response = await fetch('https://api.nileflow.internal/api/v1/sync/burst', {
          method: 'POST',
          headers: { 'Content-Type': 'application/json' },
          body: JSON.stringify(row)
        });

        if (response.ok) {
          await this.db.executeSql('DELETE FROM edge_sync_queue WHERE id = ?', [row.id]);
          synced++;
        }
      } catch (err) {
        await this.db.executeSql('UPDATE edge_sync_queue SET retry_count = retry_count + 1 WHERE id = ?', [row.id]);
      }
    }
    return { synced, remaining: results.rows.length - synced };
  }
}
```

## 7. Security, Regulatory & Deployment Guidelines

1. **Hardware Encryption**:
   - All SQLite edge databases are encrypted with **SQLCipher using AES-256 GCM**.
   - Biometric tokens stored in the secure iOS Keychain / Android Keystore.
2. **Regulatory Integrations**:
   - **NTSA GovLink**: Direct check of Driving License (Class A2) and Commercial Carrier Badges.
   - **Safaricom Daraja API**: Strict mutual TLS (mTLS) with IP-whitelisting on all payout endpoints.
3. **Continuous Deployment (CI/CD)**:
   - Automated Jest unit tests covering all 23 screen components.
   - Fastlane automated build generation for iOS TestFlight and Google Play Internal App Sharing.
