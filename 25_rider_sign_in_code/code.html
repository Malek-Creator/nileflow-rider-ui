Sign-in help

Nile Flow riders sign in with the email address and password used when the rider account was created.

info

SMS codes are not available

The rider backend does not send one-time SMS codes, so code entry is not part of sign in. Use your email and password instead.

If you cannot sign in

  1. 1

    Check that you are using the same email address you registered with. Email addresses are not case-sensitive.

  2. 2

    Re-enter the password carefully. If you have forgotten it, dispatch can help reset access for your rider account.

  3. 3

    No rider account yet? Register with your name, email, phone and vehicle details.
